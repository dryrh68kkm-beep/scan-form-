ทดสอบความเร็ว Google Apps Script ก่อนตัดสินใจสลับจาก Firestore

ต้อง deploy Code.gs และตั้งค่า gs-config.js (แก้ REPLACE_ME) ก่อนถึงจะกดทดสอบได้

เทียบเวลาที่ได้กับ Firestore REST (ปกติเปิดแอปจริงตอนนี้ใช้เวลาต่อ request <200-400ms) ถ้าตัวเลขที่ได้จาก Apps Script สูงกว่านี้มาก (เป็นวินาที) แปลว่ายืนยันสิ่งที่เตือนไว้ — การ login/เปิดแอปจะรู้สึกช้าลงชัดเจน
